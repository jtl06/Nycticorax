# Watchlist sticker asset

`nuclear-cloud.png` is a background-extracted edit of the nuclear-test photograph
selected by the project owner:
https://www.sonicbomb.com/gallery/USA/img/franklin-prime_plumbbob.jpg

The source is identified as the Franklin Prime shot, Operation Plumbbob, by:
https://www.cancerbenefits.com/cancer-benefit-programs/atomic-veterans/operation-plumbbob/

Background extraction used image editing; this is not an untouched archival photo.
The runtime applies tilt, size and opacity locally. No image service is called when
delivering a report. No source photograph is fetched at runtime.
